# CineGold – Movie Rating Analyzer

## Setup
1. pip install -r requirements.txt
2. Edit .env and set your TMDB_API_KEY (get free key at themoviedb.org)
3. streamlit run app.py

## Features
- Golden Index Score ranking
- Hidden Gems Detector (rating >= 8.0, low popularity)
- 6-tab dashboard: Charts, Table, Leaderboards, Golden Index, Hidden Gems, Export
- PDF & CSV export (dedicated Export & Reports tab)
- Auto-save to exports/ folder
- 7 interactive visualizations
